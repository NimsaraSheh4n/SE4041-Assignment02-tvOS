# CampusView TV - Xcode Migration Checklist

## Module

SE4041 - Mobile Application Design and Development

## Assignment

Assignment 02 - Part B

## Application

CampusView TV

## Platform

tvOS

---

## Purpose

This checklist describes the process required to migrate the prepared CampusView TV source code into a real Xcode tvOS project.

The source code and documentation were initially prepared using Windows and GitHub.

Final compilation, execution and testing must be completed using macOS and Xcode.

---

## 1. Required Environment

Before starting, ensure access to:

- macOS
- Xcode
- tvOS SDK
- Apple TV Simulator
- Internet connection
- Git
- Access to the GitHub repository
